# node (Node.js ≥ 18)

Required by `npx @next-ai-drawio/mcp-server` and some fireworks fallback renderers.

## Quick install

| OS | Command |
|---|---|
| macOS | `brew install node` |
| Linux (apt) | `sudo apt install nodejs npm` (may be <18); prefer NodeSource: https://nodejs.org/en/download |
| Linux (yum) | use NodeSource yum repo: https://nodejs.org/en/download |
| Windows | https://nodejs.org/en/download or `choco install nodejs-lts` |

Verify:

```bash
node --version   # must print v18.x or higher
npm --version
npx --version
```
