# python3 (≥ 3.9)

Required by the **fireworks** adapter to validate SVG and run `cairosvg`.

## Quick install

| OS | Status | Install |
|---|---|---|
| macOS | ships with macOS / `xcode-select --install` provides it | usually preinstalled; or `brew install python@3.11` |
| Linux | usually preinstalled | `sudo apt install python3 python3-pip` |
| Windows | download installer | https://www.python.org/downloads/ (check "Add to PATH"); or `choco install python` |

Verify:

```bash
python3 --version   # 3.9 or higher
python3 -m pip --version
```
