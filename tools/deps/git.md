# git

Required by setup.sh to clone upstream engine repos.

## Quick install

| OS | Command |
|---|---|
| macOS | `brew install git` (or `xcode-select --install`) |
| Linux (apt) | `sudo apt install git` |
| Linux (yum) | `sudo yum install git` |
| Windows | https://git-scm.com/download/win (or `choco install git` 管理员 PowerShell) |

Verify:

```bash
git --version
```
