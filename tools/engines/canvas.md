# Engine: Obsidian Canvas

Native `.canvas` format. Opens without plugin in Obsidian.

## Tool prereqs

**None.** The `.canvas` file opens natively in Obsidian (no plugin required).

## Check

```bash
bash tools/check.sh canvas
# OK     :: canvas     # always passes
```

## Notes

- Layout: MindMap (radial) or Freeform
- Color presets: `"1"` Red, `"2"` Orange, `"3"` Yellow, `"4"` Green, `"5"` Cyan, `"6"` Purple
- Spacing: ≥320 px horizontal, ≥200 px vertical between node centers
