# TYSZ-PPT 样式规范（天翼数字生活 · 红蓝工作汇报风）

从《关于技术治理进展的汇报》PPT 逆向提取并实测校准。**只复刻视觉样式，不取任何原文内容。**

画布：`12192000 × 6858000 EMU`（13.333in × 7.5in，16:9）。

---

## 1. 色板（克制：全套 ≤ 5 个 hex）

| 用途 | 色值 | 说明 |
|---|---|---|
| 标题 / 关键词强调 / 封面主标题 | `#C00000` | 唯一强调色，红。不要用 `FF0000`（参考件正文偶用，易刺眼） |
| 正文 | `#000000` | 需要"次要"时用黑色 + 透明度，不引入新灰阶 hex |
| 导语行 | `#404040` | 标题下的红字下方一行"观点句" |
| 表格表头底 | `#DDEBF7` | 浅蓝，配合黑色表头文字 |
| 圆角标签 / 图示蓝 | `#5B9BD5` | 面板标签、流程图块 |
| 页脚 | `#000000` + `a:alpha 55000` | 9pt，视觉灰但不新增 hex |
| 封面细分隔线 | `#000000` + `a:alpha 25000` | 高 9525 EMU 的细矩形 |

主题自带 `accent5 = 5B9BD5`、`bg1 = 白`；母版背景为纯白 `bgRef idx=1001 schemeClr bg1`。

## 2. 字体（全局唯一）

- 全部文字 **微软雅黑**（含 `latin` / `ea` / `cs` 三个 typeface 都要写）。
- 历史模板残留 `华文细黑`（版式标题占位符的覆盖样式）**必须清掉**，否则标题会回退到细黑体。
- 字号阶梯：封面标题 39pt 粗 / 页面标题 28pt 粗 / 导语 16pt 粗 / 正文 16–18pt / 表格 15pt / 页脚 9pt。

## 6. 组件规范（正文区 y 1000000–6450000）

- **表格**：表头底 `#DDEBF7` + 黑色表头字（粗体），正文行白底 + 细灰分隔线，`firstRow=1`，避免斑马纹。
- **圆角标签**：`#5B9BD5` 底 + 白字，用于示意流程节点（如图中 "AI Agent / ReAct · 取证推理"）。
- **左右双面板**：左"现状/Before"、右"目标/After"，面板边框浅灰，标题用 `#C00000`。
- **卡片网格**：2×2 或 3×2，"序号 + 小标题（红）+ 正文（黑）"结构，序号可用 `#C00000`。
- **结论/警示条**：橙色或红色文字 1 行，压在最底部（但须 ≤ `top+h 6450000`）。
- 图形优先"表格 + 文本框组合"，**避免深色底块**（参考件通篇白底）。

## 8. 已知坑（实测）

1. **全幅白矩形**：slidep / tencent-pptx 生成的内容页常盖一块 `(0,0) 12192000×6858000` 的白色矩形，会遮住版式页头 → 必须删除。
2. **占位符无几何**：`<p:spPr/>` 为空的占位符在 Keynote 里会被丢弃（标题整块不显示）→ 改为自带 `off/ext` 的文本框。
3. **wrap 折行**：封面大标题若允许自动换行，最后一个字会折行压到副标题上。
4. **字体残留**：`华文细黑` 来自版式标题覆盖样式，改字体时要把 `latin/ea/cs` 与 `endParaRPr` 一并替换。
5. **rPr 顺序**：重建 run 时必须 `solidFill → latin → ea → cs`，否则 PowerPoint 提示"需要修复"。
6. **layout 关系**：python-pptx 的 `Slide.slide_layout` 只读 → 在 zip 层改 `ppt/slides/_rels/slideN.xml.rels`。
